# اپ اندروید مانگا مترجم

اپ بومی اندروید با پایتون داخلی (**Chaquopy**) — بدون ترموکس، بدون سیستم جدا.
طراحی دقیقاً مثل وب گرادیو (همان CSS) و موتور همان `manga.py`.

## معماری
```
┌─ اپ گوشی ─────────────────────────────┐
│  WebView تمام‌صفحه (طرح گرادیو)        │
│      ↑ http://127.0.0.1:8080          │
│  app_server.py (stdlib + UI)          │
│      ↓ import                         │
│  manga.py (موتور: OCR/حباب/ترجمه)      │
│      ↓                                │
│  onnxruntime shim → ONNX Runtime جاوا │
│  opencv/numpy → ویل‌های چاکوپی اندروید │
└───────────────────────────────────────┘
```

## آپدیت خودکار از گیت‌هاب ⭐
هر بار اپ باز شود، `launcher.py` آخرین نسخه این فایل‌ها را از
`https://github.com/amirwolf512k/Manga-AutoTranslate` (شاخه main) می‌گیرد:

- `manga.py` → موتور (OCR چندزبانه، فیلترها، رندر) — **هر تغییری خودکار اعمال می‌شود**
- `manga_app.py` → نسخه/برچسب‌ها/CSS (توکن‌های طراحی) — اعمال می‌شود؛ منطق gradio مخصوص وب است
- `app_server.py` → اگر فایل UI اندروید را در ریپو بگذارید، آن هم آپدیت می‌شود

اگر `APP_VER` در `manga_app.py` ریپو از نسخه داخل اپ بالاتر بود، فایل‌ها در
حافظه خصوصی اپ ذخیره و به‌صورت خودکار اول `sys.path` قرار می‌گیرند —
**بدون نصب دوباره APK**. فقط تغییرات کاتلین/اندروید نیاز به APK جدید دارد.

## بیلد
```bash
cd android
python scripts/sync_sources.py        # کپی manga.py/manga_app.py به assets
gradle :app:assembleDebug             # یا Android Studio → Run
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

نیازمندی‌های بیلد: JDK 17 + Android SDK (API 35) + اتصال اینترنت
(چاکوپی ویل‌های numpy/opencv اندروید را از مخزن خودش می‌گیرد).

## نکته‌های نسخه اول
- **اولین اجرا**: مدل‌های OCR/تشخیص حباب دانلود می‌شوند (چند صد مگ) — وای‌فای
- پردازش فقط CPU (اندروید GPU جریان‌دار نداریم) — هر صفحه چند دقیقه طول می‌کشد
- PaddleOCR روی اندروید نصب نمی‌شود؛ موتور = RapidOCR (ONNX) + RT-DETR حباب
- فونت‌های لحن اگر در گوشی نباشند، فونت پیش‌فرض جایگزین می‌شود
