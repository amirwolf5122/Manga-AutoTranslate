اپهایِ امضاشده با کلیدِ debug گوگلپلی/Play Protect با پیامِ «ناامن»
گرفته میشوند؛ امضایِ ریلیز (v1+v2+v3) این هشدار را برطرف میکند.

- فایل: `manga-release.keystore`
- alias: `manga`
- رمز (store و key): `manga-1398-rel`

نکته: این مخزنِ عمومیِ شخصی است و کلید هم عمومی منتشر میشود؛
اگر روزی خواستی کلیدِ خصوصی بماند، همین فایل را از مخزن حذف کن و
با GitHub Secrets بساز (Workflowها مسیر `keys/manga-release.keystore`
را از ریشهٔ مخزن میخوانند).
